## 判据和步骤

`test-spec.md` §3.4 要求闻笺分别在前台、后台和手机锁屏时用卡上按键开始并停止录音，每个状态三次，每次停止后 10 秒内开始同步。停止时刻取卡首个 `0x56 rec=0`，起传时刻取目标文件的首个 `0x70`，并核对 `0x90` 大小与 `0x70` 的 EOF。若近邻的 `0x55` 稍晚，另记 #137 的检查器计时。

1. 保持闻笺在前台，让测试员用卡键开始和停止一次。App 显示录音中，停止后看到同步，随后录音列表从 63 变 64。
2. 用 iPhone Use 按 Home，确认 SpringBoard 位于前台。测试员保持屏幕解锁，用卡键开始和停止。App 未重新打开即取得协议日志。
