# 官方 App 界面走查（M1 相关页面）

**用途**　#41 写页面规格前，先看清官方 App 的页面结构、流程和文案，作为 `product-spec.md` 「先模仿、再改进」的依据
**对象**　D·NOTE App 1.0.11 安卓包里的网页资源（Capacitor + Vue 3 + Ionic，见 `official-app-analysis.md` §1）
**方法**　在本机 Chromium 里以手机尺寸运行官方网页资源，逐页截图；同时读官方的中文文案表和页面组件代码
**原始材料**　截图与脚本在仓库外：`~/WeChatProjects/REA/outputs/dnote-ui-20261107/`（含 `REPRODUCE.md`）。截图含官方图片和商标，不进仓库（ADR-005）
**日期**　2026-11-07（#41）

本文只记录结构、流程和结论，不复制官方的图片、图标和源码；引用的界面文案只用于说明。

## 1. 方法与局限

- 运行方式：本地静态服务 + 网页版 SQLite 组件；登录检查用本地伪造的 token 放行；**所有发往外网的请求都在浏览器层拦截**，没有访问官方后台。
- 录音列表用官方自带的两条演示录音；「已连接」「录音中」「暂停」「同步中」是直接改官方状态数据模拟出来的，不代表真机时序。
- 网页环境没有蓝牙，扫描页的过程状态看不到，只能从文案表和代码推断（§3.3）。
- 官方只有安卓包，样式是 Ionic 的，iOS 上的手感不能照搬。

## 2. 信息架构

```
首次启动
  录音前请确认（同意页） → 连接引导 → 扫描 → 绑定成功弹窗 → 首页

首页「全部文件」                         ← 底部左：文件
  ├─ 顶栏：设备头像 + 电量条 + 下拉箭头 → 设备切换面板（已绑定设备 / 添加）
  │         头像 → 我的设备
  ├─ 顶栏右：全局搜索、电子名片（不做）
  ├─ 「全部文件 (N)」+ 筛选排序（文件夹、来源、回收站）
  ├─ 状态卡片：录音中 / 同步进度
  └─ 录音列表 → 录音详情（来源 | 笔记）
底部中：动作按钮 → 面板（开始录音或停止录音 / 导入音频）
底部右：我的 → 会员、账户、模板社区、帮助与反馈、关于、设置（语言）
```

M1 相关路由：`/device/connect-tutorial`、`/device/scan`、`/device/select`、`/device/info`、`/device/unbind`、`/profile/bound-device-list`、`/record/detail/:id`、`/profile/settings*`。

导航特点：底部只有「文件」「我的」两个入口，中间是动作按钮；设备不占底部入口，从首页左上角进入。

## 3. 逐页记录

### 3.1 录音前请确认

- 首次进入首页时全屏显示：麦克风图标、标题「录音前请确认」、说明（先征得对方同意，避免录制敏感信息）、勾选框「我已征得对方同意」、底部「继续」按钮（勾选后才可点）。
- 按用户记一次（`recordingConsent:v1:<用户>`）。点继续后，没有已连接设备就直接跳到连接引导。

### 3.2 连接引导

- 标题「连接」；一句话指引：把设备靠近手机，按下**录音键**唤醒，**白灯闪烁**时松手（两处关键词用强调色）；中间是卡片按键示意大图；底部「继续」。
- 没有单独的权限说明页。从文案表推断：蓝牙、定位权限在扫描时直接请求，被拒时弹窗说明并引导去系统设置（网页环境无法实际观察）。

### 3.3 扫描与连接（从文案和代码推断）

- 状态文案：扫描中…、准备就绪、确保设备处于配对模式、连接到{名称}、正在连接设备…、正在读取设备信息…；扫描时显示固件版本、电量、电源状态。
- 找不到设备：弹窗「未找到设备 / 请将设备靠近你的手机」，按钮「再试一次」「稍后连接」。
- 绑定成功：弹窗「欢迎加入！你的 {设备} 激活成功」+「开始体验」。
- 绑定失败的错误码全部来自官方后台（70001～70099），后台失效后整条流程走不通——这正是本项目要解决的问题（`backend-design.md` §1.3）。
- 选择设备页 `/device/select`：两张产品卡片（标准版 / PRO），网页里 PRO 的图片缺失。

### 3.4 首页

- **空状态**：文件图标 +「暂无数据」+「连接设备开始录音」，没有操作按钮。
- **列表行**：标题（未读时前面有圆点）+「月-日 时:分 | 时长」。
- **设备区**（左上角）：设备头像；连接后显示电量条；下拉箭头展开底部面板，列出已绑定设备（名称为空时显示「未命名」）和「添加」。
- **录音中**：列表顶部插入一行状态卡片：文件名（强调色）、开始时间、跳动的音量条。
- **同步中**：状态卡片显示「正在从 {设备名} 传输录音至 App…」、百分比、进度条、速度（如 14.80KB/S）和「快传」按钮。设备名为空时文案会变成「正在从 传输录音至 App…」。
- **录音控制**：点底部中间按钮弹出面板。已连接时是「开始录音」或「停止录音」，外加「导入音频」。未连接时的行为没有观察到；同意页点「继续」后，没有已连接设备会跳到连接引导。
- **暂停和继续**：代码里有 `0x52`/`0x53` 调用，但走查（模拟状态）中没找到界面入口。
- **删除**：多选后删除，确认弹窗说明「移至回收站，30 天后自动彻底删除」；删完 Toast「已删除」。

### 3.5 录音详情

- 顶栏：返回、页签「来源 | 笔记」、分享、更多。
- **来源页签**：播放器卡片（录音开始时间、当前/总时长、进度条、播放、后退/前进按钮、倍速 x1.0），下面是 AI 大纲（时间戳可点）和转写。
- **笔记页签**：AI 总结、金句时刻，底部浮动「对此笔记提问」。
- **分享面板**：复制到剪贴板（转写、笔记）；分享文件——录音（MP3/WAV）、转写（TXT/SRT…）、笔记（MD/DOCX/PDF）、思维导图、一键导入 WPS。
- 找不到录音：「未找到该录音」；没有音频可导出：「暂无音频文件可导出」。

### 3.6 我的设备

- 顶部是卡片大图，下面电量条（未连接时显示「未连接」）。
- **未连接**：通用（名称、序列号可复制、固件版本）+ 其他（解绑，置灰）。
- **已连接**：通用（名称、录音模式、序列号、固件更新 >）；高级录音设置（VAD 声控、降噪开关、降噪等级、麦克风增益）；其他（LED 指示灯、震动马达、U 盘模式、关机、解绑）。
- 设置失败统一 Toast「设置失败」。降噪等级、麦克风增益各有子页，带一段说明。

### 3.7 断开或解绑

三个选项，各带一行说明：

| 选项 | 官方实现 | 与本项目的关系 |
|---|---|---|
| 断开连接 | 只断开蓝牙 | 可借鉴 |
| 还原所有设置 | 发 `0x93`（`restoreFactorySettings`） | **硬规则 1 禁止** |
| 解绑并清除数据 | 通知后台 → `0xA0` 解绑 → **`0x94` 格式化**（`formatDisk`） → 断开 | **硬规则 1 禁止**；官方解绑会清空卡上的录音 |

### 3.8 绑定设备列表、我的、设置、关于

- 绑定设备列表 `/profile/bound-device-list` 的数据来自后台，离线时显示「暂无已绑定的设备」，和首页下拉面板（读本地缓存）不一致。切换设备时确认「切换后将断开当前设备连接」。
- 我的：会员卡片、账户、模板社区、帮助与反馈、关于；设置页只有「语言」。
- 关于：版本号、检查更新、隐私政策、服务条款、应用权限申请与使用情况说明、个人信息收集清单、版权行。
- 权限说明页：按权限列出「申请时机」和「使用说明」（蓝牙一节写明后台保持连接用于持续接收数据）。

## 4. 对本项目的结论

**沿用**（用户换过来不用重新学）：

1. 首页就是录音列表，设备入口在左上角，下拉切换设备、添加设备。
2. 连接引导的一句话指引（录音键唤醒、白灯闪烁）和卡片按键示意。
3. 录音中、同步中都以状态卡片的形式插在列表顶部。
4. 设备页分组：通用 / 录音设置 / 其他；未连接时只显示静态信息。
5. 录音前同意提示（隐私保护，App 内首次开始录音前显示）。
6. 详情页的播放器布局（时间、进度、播放、前后跳转、倍速）。

**改进**（每条有依据）：

| # | 官方问题 | 改进 | 依据 |
|---|---|---|---|
| 1 | 解绑会格式化卡，「还原所有设置」恢复出厂 | 只保留「断开连接」和「解绑」，解绑不动卡上录音；界面上写明 | 硬规则 1、2 |
| 2 | 配对依赖后台，失败只有后台错误码 | 离线配对；按 `prd.md` §6 的错误码给出可操作的提示 | 硬规则 3 |
| 3 | 录音控制藏在中间按钮的面板里，暂停/继续没找到入口 | 首页底部常驻录音控制栏：开始、暂停/继续、停止 | `features.md` B1 |
| 4 | 同步只显示百分比和速度，看不出录音是否已安全存到手机 | 同步状态卡片写明第几条 / 共几条、是否已全部存入手机、失败是否会自动重试 | 硬规则 2、`prd.md` §4 |
| 5 | 设备名为空时文案断句（「正在从 传输…」）、显示「未命名」 | 设备名默认取蓝牙名，再退回「录音卡」 | — |
| 6 | 权限在扫描时直接弹系统窗口 | 先显示一页权限说明再请求蓝牙权限 | App Store 审核惯例、`features.md` O1a |
| 7 | 导出只有 MP3/WAV（需要转码，依赖后台或原生插件） | M1 原样导出 OGG | `features.md` E1a |
| 8 | 绑定列表依赖后台，离线时为空 | 绑定列表只存本地 | `features.md` A4a |
| 9 | 固件更新入口 | 只显示版本号；未验证版本显示提示 | 硬规则 1、7，X1 |

**M1 不做**：搜索、文件夹与回收站、导入音频、AI 笔记与提问、电子名片、会员、快传、U 盘模式、关机（`0x95` 在 M4）。
