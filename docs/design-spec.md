# 视觉规格

**用途**　全 App 的颜色、字号、圆角、组件样式和页面结构；取代 `product-spec.md` §2.5 的「视觉约定」
**来源**　#74；用户 2026-11-16 决定界面参照 beanpod（评估见 `beanpod-evaluation.md`）
**上游**　`product-spec.md`（页面、流程、文案）；ADR-008（显示名与图标）
**版本**　1.0（2026-11-16）

流程、状态、文案仍以 `product-spec.md` 为准，本文只管长什么样。

## 1. 方向

**参照什么**：beanpod 的 iPhone 设计稿（它仓库里的 `design/ui/ios_home_list.png`、`ios_detail_stage.png`）和 `Shared/Theme.swift`。取它的四样东西：

1. 暖色的纸面底，白色卡片浮在上面，不用系统的冷灰分组列表
2. 列表按天分组，每行左侧一个带底色的小图标块
3. 录音是全 App 唯一的红色动作：一个悬浮的圆形录音键
4. 录音时进入全屏深色页，只留时长、声波和三个按钮

**不照搬什么**：
- 它的吉祥物、图标、名字，那是它的品牌
- 它的强调色（设计稿是橙色，代码里后来改成玫瑰红）。我们的强调色取自闻笺图标：红 `#F52100`，米白 `#FCF7EA`
- 系统状态栏、灵动岛这些不画；用系统字体，不引入自定义字体

**保留我们自己的**：VoiceOver、动态字体、减弱动态效果的要求（原 §2.5）一条不减；硬规则 5 不变。

## 2. 设计变量

界面代码只从这里取色，不写死颜色值（#74 加静态检查）。

### 2.1 颜色

| 变量 | 浅色 | 深色 | 用在哪 |
|---|---|---|---|
| `paper` | `#F6F1E6` | `#14110F` | 页面底色 |
| `surface` | `#FFFFFF` | `#221E1B` | 卡片、输入框、播放条 |
| `line` | `#ECE5D8` | `#342E29` | 卡片描边 |
| `rule` | `#F1EBDF` | `#2A2420` | 卡片内的行分隔线 |
| `ink` | `#2A2420` | `#F6F1E6` | 正文、标题 |
| `inkMuted` | `#6B6058` | `#A89E91` | 次要文字、时间 |
| `accent` | `#B01C00` | `#FF8A70` | 选中、链接、播放进度、筛选选中态、图标线条 |
| `accentWash` | `#FBE9E4` | `#3A1E17` | 图标底块、正在播放的那一句 |
| `record` | `#F52100` | `#F52100` | 只给录音键和「结束」；上面只放白色图形，不放文字 |
| `ok` | `#3F8F4F` | `#6FBF7C` | 已连接、已存入 |
| `stage` | `#14110F` | `#14110F` | 录音页底色（两种模式下都是深色） |

- 正文与底色的对比度不低于 4.5:1。`accent` 比图标红深一档，就是为了在米白底上达到这个对比度；图标红 `record` 只用于图形。
- 警告和错误沿用系统语义色，不借用 `accent`：红色在这里的意思是「录音」，不是「出错」。

### 2.2 圆角、间距、字号

| 项 | 值 |
|---|---|
| 圆角 | 卡片、播放条、标签栏 10；按钮、图标底块、缩略图 8；小标签 6；录音键和圆形按钮是正圆；筛选项是胶囊 |
| 页面左右边距 | 20 |
| 卡片内边距 | 上下 12，左右 14 |
| 间距档位 | 4、8、12、16、24 |
| 字号 | 大标题 34 粗；详情页标题 26 粗；行标题 16 半粗；正文 15；次要 13；说明 12。全部用系统的动态字体样式映射，不写死磅值 |
| 数字 | 时间、时长、计数用等宽数字 |
| 可点区域 | 不小于 44 × 44 |
| 阴影 | 只给两处：悬浮录音键、悬浮播放条 |

## 3. 组件

| 组件 | 样子 | 取代 `product-spec.md` 里的 |
|---|---|---|
| 页面底 | `paper` 铺满，内容直接排在上面 | 系统分组列表的灰底 |
| 卡片 | `surface` 底、`line` 描边、圆角 10；行之间用 `rule` 分隔 | `List` + `.insetGrouped` |
| 录音行 | 左：40 的图标底块（`accentWash` 底，`accent` 线条）；中：标题一行，下面「时间 · 时长 · 状态」；右：重点数（有才显示） | 两行文字的列表行 |
| 设备条 | 胶囊外的圆角按钮：状态圆点、卡名、「已连接 · 电量」、下拉箭头 | DeviceChip |
| 同步状态 | 标题下的一行小字加图标；同步中时展开成卡片，带进度条和「同步完成前，卡上的录音不会被删除」 | SyncStatusCard |
| 筛选项 | 胶囊；选中是 `accent` 底白字，未选中是 `surface` 底加描边 | 无（M1.5 新增） |
| 录音键 | 64 的 `record` 正圆，中间白色圆点，悬浮在右下，带阴影 | RecordControlBar 的「开始」 |
| 录音页 | 全屏 `stage`：顶部「正在录音 · 卡名」和收起按钮；中间大号时长、声波、一句说明；底部三个 66 的圆形按钮：标重点、暂停、结束（结束是 `record` 底） | RecordingStatusCard + RecordControlBar |
| 播放条 | 悬浮在详情页底部的卡片：播放键（`accent` 底）、进度条（带重点刻度）、已播与总时长、倍速 | PlayerCard |
| 分栏 | 文字加 2 的 `accent` 下划线 | 无（M1.5 新增） |
| 提示条、Toast、确认框 | 结构照旧，底色和圆角换成本文的变量 | Banner、Toast、Modal |

录音页收起后，首页顶部留一条「正在录音 12:48」的细条，点它回到录音页。声波在开启「减弱动态效果」时静止，只显示时长。

## 4. 页面结构

分两步（#74）：

**第一步：只换样子。** 导航不动：首页还是录音列表，左上角设备条，右上角齿轮。P01～P12 的流程和文案不变，换的是底色、卡片、录音行、录音键、录音页、播放条。

**第二步：随 M1.5 改结构。**

```
底部： [ 录音 ] [ 录音卡 ]   ● 录音键
录音      列表（按天分组、筛选）→ 详情（文字稿 / 重点 两栏，底部播放条）
录音卡    原 P07 设备页的内容；切换和添加设备在页内
设置      仍从右上角齿轮进入
```

- 只有两个标签，是因为 M1.5 只有这两类内容。M2 有待办和纪要后加「总览」放在最前；M4 有对话后加「知识库」。空的标签不提前放
- 这推翻了 `product-spec.md` §2.2「不用底部标签栏」的决定。当时的理由是去掉会员、模板后「我的」只剩设置；现在设备页和以后的总览、知识库需要位置

## 5. 改版稿

三张：录音列表、录音详情、录音中。画的是 M1.5 做完后的样子（有重命名、标重点、本机文字稿，没有 AI 纪要）。链接见 #74 和 PR #69 的说明；改版稿是示意，尺寸和颜色以本文为准。
