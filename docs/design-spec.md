# 视觉规格

**用途**　全 App 的颜色、字号、圆角、组件样式和页面结构；取代 `product-spec.md` §2.5 的「视觉约定」
**来源**　#74；用户 2026-11-16 决定界面参照 beanpod（评估见 `beanpod-evaluation.md`）
**上游**　`product-spec.md`（页面、流程、文案）；ADR-008（显示名与图标）
**版本**　1.1（2026-11-18）

流程、状态、文案仍以 `product-spec.md` 为准，本文只管长什么样。

## 1. 方向

**参照什么**：beanpod 的 iPhone 设计稿（它仓库里的 `design/ui/ios_home_list.png`、`ios_detail_stage.png`）和 `Shared/Theme.swift`。取它的四样东西：

1. 暖色的纸面底，白色卡片浮在上面，不用系统的冷灰分组列表
2. 列表按天分组，每行左侧一个带底色的小图标块
3. 录音是全 App 唯一的红色动作：一个悬浮的圆形录音键
4. 录音时进入全屏深色页，只留时长、声波和三个按钮

**不照搬什么**：
- 它的吉祥物、图标、名字，那是它的品牌
- 它的强调色（设计稿是橙色，代码里后来改成玫瑰红）。我们的强调色取自闻笺图标：红 `#F52100`，米白 `#FCF7EA`
- 系统状态栏、灵动岛这些不画；用系统字体，不引入自定义字体

**保留我们自己的**：VoiceOver、动态字体、减弱动态效果的要求（原 §2.5）一条不减；硬规则 5 不变。

|---|---|---|---|

| `ink` | `#2A2420` | `#F6F1E6` | 正文、标题 |
| `inkMuted` | `#6B6058` | `#A89E91` | 次要文字、时间 |
| `accent` | `#B01C00` | `#FF8A70` | 选中、链接、播放进度、筛选选中态、图标线条 |
| `accentWash` | `#FBE9E4` | `#3A1E17` | 图标底块、正在播放的那一句 |
| `record` | `#F52100` | `#F52100` | 只给录音键和「结束」；上面只放白色图形，不放文字 |

- 正文与底色的对比度不低于 4.5:1。`accent` 比图标红深一档，就是为了在米白底上达到这个对比度；图标红 `record` 只用于图形。
- 警告和错误沿用系统语义色，不借用 `accent`：红色在这里的意思是「录音」，不是「出错」。

### 2.3 动效

动效只用来交代状态怎么变了：东西从哪来、到哪去、和什么有关。全部写在 `app/Revive/Common/Motion.swift`（iPhone 和 Mac 共用），页面里不直接写曲线；`scripts/check-motion.sh` 在 CI 里拦住其他写法。

| 变化 | 令牌 | 曲线 | 用在 |
|---|---|---|---|
| 回应一次点按 | `Motion.tap` | snappy 0.18 s | 勾待办、标星、选中筛选项、按下的键、图标换形、正在播放的句子换行 |
| 页面里出现、消失、变大小、换内容 | `Motion.standard` | smooth 0.3 s | 同步卡片展开收起、转圈换成结果、行的增减、配对步骤、录音页暂停变暗 |
| 从边上浮进来的卡片 | `Motion.overlay` | smooth 0.38 s | Toast、「留着 / 不要」 |
| 页面自己跟着走 | `Motion.follow` | smooth 0.45 s | 播放时文字稿滚到当前句 |
| 连接引导里卡上白灯 | `Motion.blink` | easeInOut 0.5 s 往复 | 只此一处 |

- 都不回弹。反复做的操作（勾、星标、筛选、播放暂停、倍速、标重点）用 `tap`，比手指慢不了
- 出现方式三种：`fade` 原地淡入（换一行字、换一个状态）；`top` 从顶边进来（浮层）；`pop` 从中心长出来（勾、星、警告这类确认标记）。Mac 的 Toast 在窗口底部，用 `bottom`
- 一个键换状态时是同一个键在变：暂停↔继续、播放↔暂停是一个按钮，图标用系统的 `symbolEffect(.replace)` 原地换形；计数用 `numericText` 滚动
- 自己画的键（录音键、录音页圆键、筛选项、播放条按键）按下时缩到 0.94，松手回来，跟手可打断（`.pressable`）
- 打开「减弱动态效果」时：不移动、不缩放，统一换成 0.2 s 淡入淡出；按下改为变暗；文字稿不跟着滚；声波和白灯静止
- 不动的地方：底部四个标签和详情页三栏的切换（和系统一样瞬切）；录音时长每秒跳字；播放进度条和已播时间；AI 流式回答逐字增长；录音列表按筛选项重排（只有筛选项本身变色）；深浅色切换
- 系统自带的转场（推入下一页、弹出 Sheet、录音页全屏、左滑删除、开关）不改

## 4. 页面结构

分两步（#74）：

**第一步：只换样子。** 导航不动：首页还是录音列表，左上角设备条，右上角齿轮。P01～P12 的流程和文案不变，换的是底色、卡片、录音行、录音键、录音页、播放条。

**第二步：改结构（#89，2026-11-18 定稿）。**

```
底部： [ 总览 ] [ 录音 ]   ●   [ 知识库 ] [ 录音卡 ]
总览      需要处理的事、没勾的待办（最多 5 条）、最近 3 条录音
录音      列表（按天分组，组标题右侧「N 条 · 总时长」；筛选）→ 详情（纪要 / 文字稿 / 改写 三栏，底部播放条）
知识库    搜索；最近整理好的纪要；跨录音提问（G3）做好后放在页首
录音卡    原 P07 设备页的内容；左上「切换」，右上齿轮进入设置
```

- 原计划只放「录音」「录音卡」两个标签、等 M2、M4 再加。用户 2026-11-18 决定和 beanpod 一样一次放齐四个：纪要和待办已经能走用户自配的 AI 服务生成，总览有内容；知识库先放搜索和最近的纪要，不放占位
- 这推翻了 `product-spec.md` §2.2「不用底部标签栏」的决定。当时的理由是去掉会员、模板后「我的」只剩设置；现在设备页、总览、知识库都需要位置
