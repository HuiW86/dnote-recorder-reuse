# 闻笺工程审计 · 2026-11-26

本轮以 GitHub 主线 `2a638e8` 为基线。优先检查三个会直接影响用户的结果：录音是否完整落盘、失败后能否恢复、内容在什么情况下会离开本机。代码审阅覆盖 iOS 与 Mac 入口、ReviveKit、Python 客户端、实验原型、后端 API 与任务、CI 和发布文件。实现与验收分别记录，便于判断哪一项能随下个版本交付。[架构与运行指南](architecture.md) · [测试规格](test-spec.md)

## 本轮修复与回归

| 范围 | 发现和处理 | 可重复核验 |
|---|---|---|
| 卡录音入库与删除 | 不足一个完整帧的文件曾能被封装成只有文件头的 OGG。转换现会拒绝该文件。旧库中时长为零、磁盘文件为空或不是普通文件的记录不能授权删除卡上原件。 | [同步集成测试](../app/ReviveKit/Tests/SyncEngineTests/SyncEngineTests.swift) 使用模拟卡校验帧边界、旧记录及删除次数。 |
| 同步中断 | 卡上同一条目可以连续报找不到，触发无休止的重列。本轮限制每次触发的自动重列次数。写入分片失败后停止接收后续片段，丢弃可疑临时文件，防止重连从错误偏移续传。 | 同一套集成测试检查重列次数，以及部分写入失败后断连、重试并逐字节核对最终 OGG。 |
| Python 下载、实验原型 | Python 客户端曾把提前到达的 EOF 当作完整文件。现在核对清单结束标志、传输状态、偏移、总长和完整帧；显式选择下载后删除时，先持久保存卡上原始字节和 OGG。同名旧备份内容不同会中止。原型中只凭名称删卡上文件的启动参数已移除。 | [客户端回归](../client/tests/test_pull.py) 经模拟 BLE 通知走实际命令入口；[字节样本](../client/tests/test_fixtures.py) 与两个 Swift 目标比对。 |
| 账号刷新 | 后端已轮换令牌但响应丢失时，重启若更换幂等键，会触发令牌复用保护。现在先持久化待处理键，重启沿用；旧会话的迟到响应不能覆盖新登录。 | [账号测试](../app/ReviveKit/Tests/AccountTests/AccountTests.swift) 覆盖旧格式、钥匙串写失败、响应丢失及切换账号。 |
| 长录音与失败清理 | 本地入库的 SHA-256 改为按 1 MiB 分块读取。云转写提前检查 24 MiB 上限，并限制读取过程中增长的文件；音频转换或存储失败后清理临时工作目录。 | [本地库](../app/ReviveKit/Tests/LibraryTests/AppDatabaseTests.swift)、[云转写](../app/ReviveKit/Tests/AssistantTests/CloudTranscriberTests.swift)和[转换测试](../app/ReviveKit/Tests/PlayerTests/PlayerTests.swift)使用合成数据。 |
| 助手入口 | MCP 列表数量参数使用可表示的正整数；无效值走现有工具错误通道，避免数字转换改变含义或中断服务。 | [MCP 测试](../app/ReviveKit/Tests/LibraryToolsTests/LibraryToolsTests.swift)。 |
| 后端配额、存储 | 队列内每条录音先按秒向上取整再求和，与实际计费一致。取消本地分片上传时，删除失败现在会反馈给清理流程，供后续重试。 | [配额边界](../backend/tests/test_usage.py)和[存储故障测试](../backend/tests/test_local_store.py)。 |
| 发布与隐私 | 应用补充自身使用的 UserDefaults、磁盘空间和文件时间戳声明；CI 从构建出的 iOS 包检查清单。欢迎页、App 内政策和外测材料说明了设备备份也可能包含录音库。本轮没有改变用户的备份设置。 | [iOS 声明](../app/Revive/PrivacyInfo.xcprivacy) · [构建检查](../.github/workflows/app-ci.yml) · [公开政策草稿](release/privacy-policy.md) · [Apple 对 Application Support 备份的说明](https://developer.apple.com/library/archive/documentation/FileManagement/Conceptual/FileSystemProgrammingGuide/FileSystemOverview/FileSystemOverview.html) |
