# ADR-005：先用代号 Revive，不使用对方商标

**日期**　2026-11-06
**状态**　Accepted
**来源**　#26（父 issue #10）

## 背景

- 「D·NOTE」「追觅」「Dreame」「DreameNote」都是对方的商标或产品名，不能当作我们的 App 名称、图标或 Bundle ID 的一部分。
- 分发先走 TestFlight（ADR-004），App 名称以后可以改。
- 用户需要知道这个 App 能连他们的卡，所以描述里要说明兼容哪款设备。

## 候选方案

| 方案 | 优点 | 缺点 |
|---|---|---|
| **先用代号，上架前再定正式名** | 不阻塞开发；不必现在做商标检索 | 以后改名要改显示名、图标和文案 |
| 现在就定正式名 | 一次到位 | 要做商标检索，拖慢阶段 1 |
| 用带 D·NOTE 的名字 | 用户一看就懂 | 侵权风险，审核可能被拒 |

## 决定

- 代号 **Revive**（取「让这批卡重新可用」之意），用于 App 显示名、工程名和 Bundle ID（`com.huiw86.revive`）。
- 描述里只做事实说明：「适用于 D·NOTE 录音卡」，并声明与追觅无关联；不使用对方 logo 或界面截图。
- 正式名在决定上架时（ADR-004 的触发条件）另开 ADR。

## 后果

- 正面：开发不被命名阻塞。
- 负面：上架前要改名，TestFlight 用户会看到名称变化。
- 反悔成本：改显示名和图标成本低；**Bundle ID 一经上传到 App Store Connect 就不能改**，所以 Bundle ID 用中性的代号，不随正式名变化。
